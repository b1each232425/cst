# Question 组件使用指南

## 概述

本指南将详细介绍如何在考试系统中使用 Question 组件来展示和处理五种不同类型的题目。通过参考 `+page.svelte` 文件中的 `examQuestions` 格式，我们可以了解每种题型的正确配置方法。

## 题目类型说明

在系统中，题目类型使用特定的代码表示：
- `00`: 单选题
- `02`: 多选题
- `04`: 判断题
- `06`: 填空题
- `08`: 简答题

## 基本使用方法

所有题型都需要导入 Question 组件并传入必要的参数：

```svelte
<script>
  import Question from "$lib/component/QuestionAnswer/question.svelte";
  
  // 题目数据
  const question = {
    // 题目配置（根据题型不同而变化）
  };
  
  // 题目在列表中的索引
  const index = 0;
  
  // 是否为预览模式
  const ifPreview = false;
</script>

<Question {question} {index} {ifPreview}></Question>
```

## 各题型配置详解（都需要加入ifPreview）（组件的index属性是题目旁边的序号，如果不想加就直接不加就好）

### 1. 单选题 (type: "00")

单选题需要提供题目内容和选项数组，每个选项包含标签和值。

```javascript
{
  id: "1001",
  type: "00",
  group_name: "一、单选题（9分）",
  content: "<p>Svelte 的主要特点是什么？</p>",
  options: [
    { label: "A", value: "运行时框架" },
    { label: "B", value: "编译时框架" },
    { label: "C", value: "虚拟DOM框架" },
    { label: "D", value: "服务端渲染框架" }
  ]
}
```

使用示例：

```svelte
<script>
  import Question from "$lib/component/QuestionAnswer/question.svelte";
  
  const singleChoiceQuestion = {
    id: "1001",
    type: "00",
    group_name: "一、单选题",
    content: "<p>Svelte 的主要特点是什么？</p>",
    options: [
      { label: "A", value: "运行时框架" },
      { label: "B", value: "编译时框架" },
      { label: "C", value: "虚拟DOM框架" },
      { label: "D", value: "服务端渲染框架" }
    ]
  };
</script>

<Question question={singleChoiceQuestion} index={0}></Question>
```

### 2. 多选题 (type: "02")

多选题的配置与单选题类似，但允许用户选择多个选项。

```javascript
{
  id: "2001",
  type: "02",
  group_name: "二、多选题（10分）",
  content: "<p>以下哪些是 JavaScript 框架或库？</p>",
  options: [
    { label: "A", value: "React" },
    { label: "B", value: "Svelte" },
    { label: "C", value: "Python" },
    { label: "D", value: "Vue" },
    { label: "E", value: "Angular" }
  ]
}
```

使用示例：

```svelte
<script>
  import Question from "$lib/component/QuestionAnswer/question.svelte";
  
  const multiChoiceQuestion = {
    id: "2001",
    type: "02",
    group_name: "二、多选题",
    content: "<p>以下哪些是 JavaScript 框架或库？</p>",
    options: [
      { label: "A", value: "React" },
      { label: "B", value: "Svelte" },
      { label: "C", value: "Python" },
      { label: "D", value: "Vue" },
      { label: "E", value: "Angular" }
    ]
  };
</script>

<Question question={multiChoiceQuestion} index={0}></Question>
```

### 3. 判断题 (type: "04")

判断题只需提供题目内容，选项通常是固定的"正确"和"错误"。

```javascript
{
  id: "3001",
  type: "04",
  group_name: "三、判断题（5分）",
  content: "<p>Svelte 是一个编译时框架，不使用虚拟DOM。</p>"
}
```

使用示例：

```svelte
<script>
  import Question from "$lib/component/QuestionAnswer/question.svelte";
  
  const judgementQuestion = {
    id: "3001",
    type: "04",
    group_name: "三、判断题",
    content: "<p>Svelte 是一个编译时框架，不使用虚拟DOM。</p>"
  };
</script>

<Question question={judgementQuestion} index={0}></Question>
```

### 4. 填空题 (type: "06")

填空题需要指定答案数量（即填空的数量），系统会为每个空生成一个输入框。

```javascript
{
  id: "4001",
  type: "06",
  group_name: "四、填空题（10分）",
  content: "<p>Svelte 的文件扩展名是 ______，它的创建者是 ______。</p>",
  answer_num: 2  // 表示有两个需要填写的空
}
```

使用示例：

```svelte
<script>
  import Question from "$lib/component/QuestionAnswer/question.svelte";
  
  const fillBlankQuestion = {
    id: "4001",
    type: "06",
    group_name: "四、填空题",
    content: "<p>Svelte 的文件扩展名是 ______，它的创建者是 ______。</p>",
    answer_num: 2
  };
</script>

<Question question={fillBlankQuestion} index={0}></Question>
```

### 5. 简答题 (type: "08")

简答题提供富文本编辑器让用户输入答案，可以通过 `answer_num` 指定需要回答的问题数量。

```javascript
{
  id: "5001",
  type: "08",
  group_name: "五、简答题（20分）",
  content: "<p>请简述 Svelte 与 React 的主要区别。</p>",
  answer_num: 1  // 默认为1，表示只有一个富文本编辑器
}
```

使用示例：

```svelte
<script>
  import Question from "$lib/component/QuestionAnswer/question.svelte";
  
  const essayQuestion = {
    id: "5001",
    type: "08",
    group_name: "五、简答题",
    content: "<p>请简述 Svelte 与 React 的主要区别。</p>",
    answer_num: 1
  };
</script>

<Question question={essayQuestion} index={0}></Question>
```

## 高级配置

### 预览模式

通过设置 `ifPreview` 属性为 `true`，可以启用预览模式，此时填写答案不会发送到后端：

```svelte
<Question question={question} index={0} ifPreview={true}></Question>
```

### 题目分组

在考试页面中，可以通过 `group_name` 属性对题目进行分组，系统会自动根据不同的 `group_name` 生成题目分组：

```javascript
// 在 examQuestions 数组中
[
  { 
    id: "1001", 
    type: "00", 
    group_name: "一、单选题（9分）",
    // 其他属性
  },
  // 更多单选题...
  
  { 
    id: "2001", 
    type: "02", 
    group_name: "二、多选题（10分）",
    // 其他属性
  },
  // 更多多选题...
]
```

## 答案保存机制

系统会自动保存用户的答案，具体实现在 `answer.svelte` 组件中：

- 单选题、多选题和判断题：用户选择选项后自动保存
- 填空题：用户输入后自动保存
- 简答题：用户在富文本编辑器中编辑后，系统会在内容变化后延迟1秒保存

## 注意事项

1. 确保每个题目都有唯一的 `id`
2. 题目类型必须使用正确的代码（`00`, `02`, `04`, `06`, `08`）
3. 富文本内容使用HTML格式，支持基本的HTML标签
4. 在预览模式下，用户无法编辑答案
